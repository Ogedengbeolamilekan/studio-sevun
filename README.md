# Studio Sevun website

Static HTML website. Upload the **contents of this folder** to the root of a GitHub repository, keeping `index.html`, `assets/` and `projects/` together.

For GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root). The site will be served at your GitHub Pages URL.

The contact links currently include a WhatsApp number and a placeholder email (`hello@studiosevun.com`); verify the email before launch.

No build command is required.
